### 🚀 Proyectos destacados
 
#### 🏢 [Condominio Vista Verde](https://github.com/C-HARLY/CondominioVistaVerdeUMG): sistema de administración residencial
 
Aplicación de escritorio para administrar un condominio: propietarios, casas, cuotas de mantenimiento, pagos, estados de cuenta y reporte de casas morosas. Fui **Scrum Master** de un equipo de 5 personas y gestioné los sprints en Jira.
 
| Componente | Tecnología | Propósito en el proyecto |
| :--- | :--- | :--- |
| **Lógica e interfaz** | Java 21 + JavaFX | Reglas de negocio (cuotas, pagos, estados de cuenta) e interfaz de escritorio. |
| **Base de datos** | PostgreSQL (Neon) + HikariCP | Base relacional en la nube con pool de conexiones. |
| **Reportes** | JasperReports | Reporte general y reporte de casas morosas en PDF. |
| **Notificaciones** | Jakarta Mail (SMTP) | Envío de comprobantes de pago por correo a los propietarios. |
| **Build y gestión** | Maven + Jira | Construcción del proyecto y seguimiento de sprints con Scrum. |
